Veyra 0.4.0 alpha brings an independent settings hub and a more consistent Material You interface.

### Download and install

Requires Android 9 or newer. Install **one** standalone APK matching your device:

| APK | Device |
| --- | --- |
| **[Veyra-0.4.0-arm64-v8a-debug.apk](https://github.com/Tufein/Veyra/releases/download/v0.4.0/Veyra-0.4.0-arm64-v8a-debug.apk)** | Most modern Android phones and handhelds; choose this if unsure |
| [Veyra-0.4.0-armeabi-v7a-debug.apk](https://github.com/Tufein/Veyra/releases/download/v0.4.0/Veyra-0.4.0-armeabi-v7a-debug.apk) | Older 32-bit ARM devices |
| [Veyra-0.4.0-x86_64-debug.apk](https://github.com/Tufein/Veyra/releases/download/v0.4.0/Veyra-0.4.0-x86_64-debug.apk) | x86_64 Android devices/emulators |

The attached `SHA256SUMS.txt` contains checksums for all three APKs. No split installer is needed.

### What changed

- Independent settings overview with search, dedicated detail pages, and Back navigation within settings.
- Refined Material You typography, tonal cards, light/dark palettes, accent selection, and a live palette preview. Theme choices stack on small screens with large text.
- Shortcut management stays inside settings, with validated addresses and the existing eight-shortcut limit.
- Settings navigation, scroll positions, and unsaved name/shortcut forms survive activity recreation.
- The start page uses the selected palette. Existing preference keys, bookmarks, shortcuts, and saved tab addresses are retained by the app.
- An expanded [product roadmap](https://github.com/Tufein/Veyra/blob/v0.4.0/ROADMAP.md) covers reliable updates, browsing features, extensions, handhelds, privacy, and stable-release criteria.

Firefox extension support through GeckoView and the Mozilla Add-ons catalog remains available from 0.3.0; compatibility varies by extension.

### Validation and known alpha limitations

- All 31 JVM tests and 6 browser-protection tests passed; Android Lint reported zero findings. The APKs are built and their signatures verified by GitHub Actions before publication.
- Settings tests render actual Android/Material widgets using Robolectric, including Android 9 fallback and large-text layouts. These renderings are not physical-device screenshots. The connected-test APK builds, but device tests have not been run successfully.
- Live Gecko browsing, app-side extension installation, wallpaper colors, and signed updates retaining data still require device validation. This is a testing alpha, not a stable release.
- **These APKs are debug-signed.** Each GitHub Actions runner can generate a different signing key. An update over 0.3.0 or another build may be rejected because its certificate differs; a higher version number alone does not resolve that. A stable signing strategy is planned for 0.4.1.
- **Uninstalling Veyra deletes its local app data**, including settings, bookmarks, tabs, and the Gecko profile. Do not uninstall an existing installation to resolve a signing conflict if you need to keep that data. In-place update compatibility has not been established for these alpha packages.

See [verification details](https://github.com/Tufein/Veyra/blob/v0.4.0/docs/verification-0.4.md) and [settings design](https://github.com/Tufein/Veyra/blob/v0.4.0/docs/settings-design.md).

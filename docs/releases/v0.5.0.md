# Veyra 0.5.0 — Alpha candidate

This candidate brings the daily-browser roadmap into one build: local history, authenticated-response downloads, backups, website permissions/data controls, real private tabs, custom search, fullscreen media and manual encrypted bookmark/start-page sync. Settings add tablet navigation and complete Dutch/English resources. Bookmarks and shortcuts retain shared names/addresses and explicit pinning; large lists load in pages.

Firefox extension support adds clearer rights summaries, tab API handling and disable-all recovery. uBlock Origin, Dark Reader and ClearURLs remain device-test candidates; a verified package download is not proof of compatibility.

## Read before installing

**The signing certificate changes from older public alphas. Export your data before uninstalling an existing Veyra.** The old ephemeral CI private keys are unavailable. Follow [signing and migration](../signing-and-migration.md) for a read-only USB export of bookmarks, shortcuts, supported preferences and optional normal-tab addresses. Website logins, cookies, extension data and form contents cannot be migrated by this tool. Future public APKs must keep this new fixed key.

Package `nl.veyra.browser`; version code 7; Android 9+. The three standalone APKs target `arm64-v8a`, `armeabi-v7a` and `x86_64`. They remain **debuggable alpha builds**. Check `SHA256SUMS.txt` and the [pinned certificate](../signing-certificate-sha256.txt).

## Verification and limits

Local checks passed: 104 JVM tests, 8 builtin-protection tests, 8 Python migration/signing tests, Android Lint with 0 findings, app/test-APK builds and certificate/checksum validation. See [full evidence](../verification-0.5.md).

Physical-device installation/update, logged-in/interrupted downloads, private cookie isolation after process death, three-extension compatibility, two-device sync, TalkBack/controller and performance measurements remain open. No stable 1.0 claim is made. Private mode is not network anonymity; deliberately saved files/bookmarks/clipboard can persist. Download retry reopens the source instead of replaying earlier POST data.

Sync requires your own HTTPS/WebDAV file server with strong ETags/conditional PUT; no hosted Veyra/Firefox account service is provided. Only bookmarks and shortcuts sync. Read [protocol and recovery](../sync.md) and [privacy/data behavior](../privacy.md). Passkeys can open an external browser, whose login session stays there.

These APKs were built and checked locally with the fixed certificate, then uploaded directly. The repository Secrets API returns HTTP 403, so automatic fixed-key release builds are not yet provisioned. This release does not claim that release CI or the physical-device gates passed.

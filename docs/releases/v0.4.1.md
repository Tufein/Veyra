Veyra 0.4.1 alpha improves the browser menu, tabs, settings, and the relationship between bookmarks and start-page shortcuts.

### Download

Requires Android 9+. Install one standalone APK:

- **[ARM64 APK — most modern phones](https://github.com/Tufein/Veyra/releases/download/v0.4.1/Veyra-0.4.1-arm64-v8a-debug.apk)**
- [Older 32-bit ARM devices](https://github.com/Tufein/Veyra/releases/download/v0.4.1/Veyra-0.4.1-armeabi-v7a-debug.apk)
- [x86_64 devices/emulators](https://github.com/Tufein/Veyra/releases/download/v0.4.1/Veyra-0.4.1-x86_64-debug.apk)

`SHA256SUMS.txt` contains checksums for all three APKs. No split installer is needed.

### Changes

- Material bottom panels replace the long browser menu and tab dialog, with icons, clear selection, separate close buttons, and layouts that adapt to large text.
- One searchable library for bookmarks and start-page shortcuts. Pin a bookmark to the start page, unpin it while keeping the bookmark, and edit linked names/addresses together. Deleting a bookmark and its pin requires confirmation.
- Compact settings rows, shared website monograms, no duplicate detail headings, and a smaller start-page introduction.
- Library search, selected tab, and editor drafts survive recreation. Existing preference keys and saved-site JSON remain compatible; no automatic migration rewrites user data.
- Firefox extension support remains available through GeckoView and Mozilla Add-ons; compatibility varies by extension.

[Screen previews and behavior](https://github.com/Tufein/Veyra/blob/v0.4.1/docs/library-design.md).

### Validation and alpha limits

59 JVM tests and 6 browser-protection tests passed, with zero Lint findings. The release workflow builds all three APKs, verifies their signatures, and checks asset checksums before publishing.

UI previews render actual Android/Material widgets with Robolectric; they are not physical-device screenshots. Live Gecko browsing, extension installation, system gestures, and signed updates retaining data still require device validation.

**These are debug-signed testing APKs.** Different CI runners can generate different signing keys, so installing over an earlier alpha may fail with a signature conflict. Stable signing and update validation remain open roadmap work; this design release does not complete them. **Uninstalling deletes local app data. Do not uninstall an existing installation to resolve a conflict if you need to keep its data.**

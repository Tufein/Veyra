The first downloadable alpha release of Veyra, an Android browser with Material You settings and Firefox extension support through GeckoView.

### Downloads

Android 9 or newer is required. Download and install **one** APK matching your device:

| APK | Device |
| --- | --- |
| **Veyra-0.3.0-arm64-v8a-debug.apk** | Most modern Android phones and handhelds — choose this if unsure |
| Veyra-0.3.0-armeabi-v7a-debug.apk | Older 32-bit ARM devices |
| Veyra-0.3.0-x86_64-debug.apk | x86_64 Android emulators/devices |

`SHA256SUMS.txt` contains checksums for all three APKs. Each APK is standalone; no additional split APKs or installer app are needed.

### Included

- Full-screen Material 3 settings with wallpaper colors on Android 12+, light/dark/system themes, accent colors, switches, and a text-size slider.
- Mozilla Add-ons catalog for Firefox on Android, permission consent, installation, enable/disable, manual updates, removal, extension popups, and options pages. Compatibility varies by extension.
- GeckoView browsing engine, local ad/tracker blocking, per-site exceptions, HTTPS controls, tabs, bookmarks, shortcuts, and Android Autofill integration.

### Validation and alpha limitations

- APK builds, all 12 JVM tests, all 6 browser-protection tests, and Android Lint passed; Lint reported no findings.
- APK signatures have been verified. These are **debug-signed alpha builds** built by GitHub Actions, not production/Play Store packages. Earlier locally shared APKs can use a different signing certificate. Updating an existing Veyra installation requires the same signing certificate.
- Device tests, visual inspection, live Gecko browsing, and app-side extension installation remain unverified: the cloud software emulators did not complete a usable test run. This release is for testing and feedback.
- Switching from the earlier WebView engine retains settings, bookmarks, shortcuts, and saved web addresses, but website cookies and login sessions use a separate Gecko profile. Websites require signing in again.

See `docs/verification-0.3.md` for validation details and remaining device checks.

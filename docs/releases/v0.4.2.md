Veyra 0.4.2 alpha opens Android Autofill settings directly.

### Download

Android 9+. Install one standalone APK:

- **[ARM64 — most modern phones](https://github.com/Tufein/Veyra/releases/download/v0.4.2/Veyra-0.4.2-arm64-v8a-debug.apk)**
- [32-bit ARM](https://github.com/Tufein/Veyra/releases/download/v0.4.2/Veyra-0.4.2-armeabi-v7a-debug.apk)
- [x86_64](https://github.com/Tufein/Veyra/releases/download/v0.4.2/Veyra-0.4.2-x86_64-debug.apk)

Checksums are attached as `SHA256SUMS.txt`.

### Fix

The **Autofill-instellingen openen** button opens Android’s Autofill provider picker directly, using the public system action and the requesting app’s package URI. Browser credential actions use the same route. Devices without that route fall back to general Android settings. Returning refreshes the displayed provider status. The settings guidance and button labels match the new behavior.

Includes the shared bookmarks/start-page library and Material browser/settings design from 0.4.1.

### Validation and limits

The updated settings tests verify the direct intent, package URI, and provider-status refresh. GitHub Actions builds all three APKs, runs the full JVM and browser-protection suites plus Lint, verifies APK signatures, and checks asset integrity before publication. Physical-device and live Gecko validation remain outstanding.

**Debug-signed testing builds:** different CI runners may use different signing keys, so an update over an earlier alpha can fail with a signature conflict. Stable signing is still open roadmap work. **Uninstalling deletes local app data; do not uninstall to resolve a conflict if you need to retain it.**
